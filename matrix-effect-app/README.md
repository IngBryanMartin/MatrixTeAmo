# Matrix Effect App

## Description
The Matrix Effect App is a simple web application that simulates the iconic falling text effect from the Matrix movie. The application displays the phrase "TE AMO" falling from the top of the screen in vibrant rainbow colors.

## Files
- `src/index.html`: Contains the HTML structure for the application, including a canvas element for rendering the matrix effect. Contains the styles for the application, setting the background color and font properties. Contains the JavaScript code that creates the matrix effect and animates the falling text.

## How to Run the Application
1. Clone the repository to your local machine.
2. Navigate to the project directory.
3. Open `src/matrix.html` in your web browser.

## Features
- Animated falling text effect.
- Colorful rainbow text.
- Simple and lightweight implementation.

- HTML
